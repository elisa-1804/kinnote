# 🦝 KinNote

**KinNote** — это личная библиотека для структурированного хранения просмотренных фильмов и сериалов.

🚀 **[Открыть сайт](https://raccolis.github.io/kinnote/)**

---

### 🍿 Что умеет проект:
* **Личный архив:** Удобный учет и структурированная история всех ваших просмотров.
* **Фильмы «в стопках»:** Франшизы и многосерийные фильмы аккуратно разложены по частям.
* **Колесо Фортуны:** Встроенная рулетка, которая помогает решить вечную проблему «что посмотреть» и выбивает случайную карточку фильма.
* **Ироничная статистика:** Счетчик, который честно считает, сколько часов жизни вы потратили на любимый контент.
* **Избранное:** Быстрый доступ к самому любимому кино.
* **Кнопки-телепорты:** Мгновенный переход к трейлеру или поиску фильма в браузере.
